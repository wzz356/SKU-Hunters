# 最终企划案 = WHY → WHAT → HOW → BUSINESS

> 企划案不是"一张 AI 商品图 + 几句介绍"，而是回答"为什么是这个产品"。
> 每个模块对应本目录下一个子文件夹，参考图和产出物都往里放。

## ① 企划背景（WHY 为什么做）
- 市场机会 / 用户需求 / 趋势 / 品类机会
- 数据来自洞察驾驶舱三官（FeatureMatrix / UserSentiment / IPAssessment），每条挂 EvidenceRef
- 例：情绪消费 ↑32%、"办公室风扇太丑"原声 1,284 条

## ② 商品定位（WHAT 给谁做）
- 目标人群（如 18-30 岁年轻女性）
- 场景清单（办公室/宿舍/咖啡店/户外）
- 价格带（如 ¥39-79）
- 一句话定位："面向年轻女性的高颜值、IP化、情绪价值型便携风扇"

## ③ 产品设计（HOW 怎么设计）——最重要
- 产品概念图（大图）
- Moodboard（图片拼贴）
- 设计语言关键词（植物/蝴蝶/玻璃瓶/晨露/治愈）
- 色彩（薄荷绿/奶油白/浅粉）
- 材质（透明PC/磨砂/软胶）
- 图案（蝴蝶/叶片/水波纹）

## ④ 功能规格（HOW 怎么做成商品）
- 规格表：风力三档 / USB-C / 磁吸IP挂件 / 可替换外壳 / 折叠支架 / ≤250g
- 这一步让 idea 变成商品

## ⑤ 商业企划（BUSINESS 怎么卖）
- 成本目标 ≤25元 / 建议零售价 59元 / 目标毛利
- SKU 结构：基础款 / IP款 / 限定款
- 上新节奏：3月预热 → 4月首发 → 5月IP扩展 → 6月第二波补货

## ⑥ 商业化路径（BUSINESS 怎么做大）——对应 GTMPlan 契约
- 路径图：趋势发现 → 首款测试 → 小规模上市 → 销售/用户反馈 → 爆款验证 → IP联名 → 系列化扩展
- 回答："这个商品如果成功，名创下一步怎么把它做大？"
- 落地数据：国家批次、当地价格带、上市时点、本地化要点
