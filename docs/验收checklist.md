## 一、Phase 1+2 验收：保温杯全链路（核心门槛，绿了才进 Phase 3）

### 新建企划 → 机会卡
- [ ] 新建企划：品类=保温杯、IP 策略=迪士尼，提交后能进入任务页
- [ ] 任务页标题和第 0 步显示的是**本任务的 brief**（保温杯/迪士尼），不是小风扇 demo 数据
- [ ] 机会卡第一张是**迪士尼联名款**（标题含"迪士尼"），不是三丽鸥
- [ ] 机会卡的价格带不是永远固定的"49-99 元"

### 洞察驾驶舱
- [ ] 显示保温杯真实社媒数据（非小风扇）
- [ ] 竞品区能看到 **9 张真实商品图**，不是灰块
- [ ] 趋势折线图正常渲染（heatCurve 不为 null 导致白屏/报错）
- [ ] 色板有色值显示，不是空白块

### 企划卡 + 即梦
- [ ] 点选机会卡 → 企划卡正常生成，**不出现 404**
- [ ] 后端日志出现 `CVSync2AsyncSubmitTask`（证明即梦 API 真调了）
- [ ] 即梦失败时降级为占位图，页面不崩
- [ ] 企划卡含完整模块：概念图 / 设计语言 / 功能规格 / 定价+成本校验 / 上新节奏 / Moodboard / SKU 分级 / 商业化路径
- [ ] 成本校验数字随 brief 的成本上限变化（改成本上限重新生成，结论应变）

### 改稿 + 归档
- [ ] 改稿框输入修改意见 → 回复是 LLM 针对性回答，不是固定话术
- [ ] 归档后回任务中心，该任务状态显示"已归档"
- [ ] 刷新页面后任务状态不丢（持久化生效）

### 断网兜底
- [ ] 关掉后端，前端用本地 mock 完整走通 demo 任务，**不白屏**

## 二、Phase 3 验收：视觉

- [ ] 无紫色渐变与红色混用打架的页面

- [ ] 任务中心状态只出现五种：brief_locked / insights_ready / opportunities_ready / plan_card_ready / archived（无臆造的 running/failed）
- [ ] 全站字体层级统一（页标题 20 / 卡片标题 15 / 正文 13 / 辅助 12）
