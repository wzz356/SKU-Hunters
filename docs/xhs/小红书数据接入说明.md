# 小红书数据接入 · 第一阶段运行说明

> 为 SKU Hunters「AI 新品企划工作室」增加小红书公开内容数据的**本地导入、清洗、去重与统计**能力，为后续数据看板接入真实数据做准备。
>
> 本阶段**不包含任何实时采集**：无合法数据源时不造假"实时小红书数据"，仅完成本地导入链路 + 样例/Mock 验证。

---

## 一、范围与边界

**本阶段实现**
- 新增独立 SQLite 库 `backend/data/xhs.db`（与 v2 企划流程的 `committee.db` 完全隔离）
- `xhs_notes`（笔记表）与 `xhs_ingestion_runs`（导入运行记录表）
- JSON / CSV 批量导入器：按 `note_url` 去重、字段缺失/非法数字/重复处理、隐私过滤
- 统计服务与 API：关键词数量、互动量与互动率、高频标签、发布时间趋势、Top 笔记、基础文本词频
- 测试与示例数据

**数据来源边界（严格）**
- 仅处理小红书官方授权 API、官方导出文件或用户提供的公开数据文件
- **不实现**验证码绕过、登录破解、反爬绕过、批量注册、高频抓取
- 每条数据保留 `source_type`、`source_url`、`captured_at` 来源信息
- 不保存手机号、真实姓名、私信、登录凭证等隐私数据

---

## 二、数据库与表结构

- **数据库位置**：`backend/data/xhs.db`（首次导入/连接时自动创建）
- 表由 `backend/app/xhs/store.py` 自动建表

### `xhs_notes` 笔记表

| 列 | 类型 | 说明 |
|:---|:---|:---|
| `id` | TEXT PRIMARY KEY | 笔记 id（缺省由 note_url 派生） |
| `note_url` | TEXT UNIQUE | 笔记链接（去重主键） |
| `title` / `content` | TEXT | 标题 / 正文（已脱敏） |
| `publish_time` | TEXT | 发布时间 |
| `likes` / `collects` / `comments` | INTEGER | 点赞 / 收藏 / 评论 |
| `views` | INTEGER | 曝光量（可选扩展列，用于真实互动率，无则留空） |
| `tags` | TEXT | 标签 JSON 数组 |
| `query_keyword` | TEXT | 采集关键词 |
| `captured_at` | TEXT | 采集时间 |
| `source_type` | TEXT | 来源类型（默认 `xhs`） |
| `source_url` | TEXT | 来源链接（默认 = note_url） |
| `created_at` | TEXT | 入库时间 |

> **说明**：`views` 为扩展列（用户字段集之外的可选字段），用于在有曝光数据时计算真实互动率；无 views 时互动率以降级代理方式返回（见第六节）。

### `xhs_ingestion_runs` 导入运行记录表

记录每次导入的 `keyword`、`file_path`、`status`（success/partial/failed）、`total`、`inserted`、`updated`、`skipped`、`invalid`、`started_at`、`finished_at`、`message`。

## 三、导入

### 3.1 数据文件格式

**JSON**：顶层为 `list`，或 `{"notes": [...]}`、`{"items": [...]}` 等包裹结构。示例见 `data/xhs/sample_notes.json`。

**CSV**：表头需包含字段（支持中英文别名），示例见 `data/xhs/sample_notes.csv`。

字段别名（导入器自动识别）：`note_url/url/link`、`title/标题`、`likes/点赞`、`collects/收藏`、`comments/评论`、`tags/标签`、`keyword/关键词`、`publish_time/发布时间` 等。

### 3.2 清洗与去重规则

- **按 `note_url` 去重**：同批次多条保留 `captured_at` 最新的一条；跨批次按唯一键 `note_url` upsert（更新已存在记录）。
- **非法数字**：`likes/collects/comments/views` 非法值归 `NULL`（不抛异常）。
- **缺失字段**：补默认值（`query_keyword` 空串、`source_type=xhs`、`source_url=note_url`、`captured_at=当前时间`）。
- **tags**：兼容数组或 `a,b,c` / `a;b` 分隔字符串，自动规范化。

### 3.3 隐私过滤

- 字段名命中隐私词（`phone/mobile/real_name/password/token/secret/private_message/dm/chat/cookie/...`）的**整条记录拒收**（计入 `invalid`）。
- 文本内容中的大陆手机号、18 位身份证、邮箱、AK/SK 自动脱敏为 `[已脱敏]`。
- 隐私字段**不落库**（store 层 schema 也没有这些列）。

### 3.4 CLI 导入命令

```bash
cd backend

# 导入单个/多个 JSON/CSV 文件到默认库 backend/data/xhs.db
./.venv/Scripts/python.exe -m app.xhs.ingestor ../data/xhs/sample_notes.json

# 批量导入多个文件，并标注关键词
./.venv/Scripts/python.exe -m app.xhs.ingestor \
    ../data/xhs/sample_notes.json ../data/xhs/sample_notes.csv \
    --keyword 示例

# 指定自定义库路径（测试/临时用）
./.venv/Scripts/python.exe -m app.xhs.ingestor file.json --db /tmp/xhs.db
```

导入结束会打印 JSON 汇总：`summary`（inserted/updated/skipped/invalid/total）与每条 `run` 记录。

### 3.5 API 导入

```bash
curl -X POST http://localhost:8000/api/v1/xhs/ingest \
  -H "Content-Type: application/json" \
  -d '{"paths": ["backend/../data/xhs/sample_notes.json", "backend/../data/xhs/sample_notes.csv"], "keyword": "示例"}'
```

> `paths` 为服务端可访问的本地文件路径（相对后端工作目录或绝对路径）。

## 六、统计口径说明（诚实标注）

**互动量与互动率**
- `interactions = likes + collects + comments`
- **互动率有两条路径**：
  - 若笔记含 `views`（曝光）字段：`engagement_rate = interactions / views`，返回 `basis="views"`（真实曝光转化率）
  - 若无曝光字段（本阶段样例无 views）：返回 `engagement_rate = interactions / note_count`（人均互动量），并标注 `basis="avg_per_note"`——**是互动强度代理，不是真实曝光转化率**，不伪装。

**词频**：对 `title + content` 提取英文单词与 2 字以上中文词组，过滤常见停用词后统计 Top N。
