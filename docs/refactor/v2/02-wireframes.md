> **背景统一（v1.1 修正）**：App 视口背景 = 暖灰 `#F7F7F8`；页面内容面板 = 白色 `#FFFFFF`。不再有「Content 白底」与「暖灰页面背景」的矛盾。

## 6. 移动端（375px）规范

| 项 | 方案 |
|----|------|
| 导航 | 抽屉导航（汉堡按钮呼出，遮罩层） |
| 主 CTA | 底部固定操作区（sticky footer），拇指可达 |
| 表格 | 横向滚动（`overflow-x: auto`）或卡片化 |
| 图表 | 随容器 resize；小屏下图表降级为关键数值卡 + 摘要 |
| 任务卡 | 单列（Col xs24） |
| 触控 | 可点击目标 ≥44×44px |

## 7. 边界文本测试（渲染前必测）

- 长中文标题（如「2027 夏季户外生活系列 × 小风扇 × 18-30 岁年轻女性情绪价值款」）
- 长英文/长 URL（证据链接）
- 超长证据标题（evidence.title 截断 + 完整内容进 Popover）
- 缺失图片（概念图/竞品图 → 占位）
- 空数据（无机会卡/无洞察 → Empty）

---

## 8. 通用区块规范

- **主 CTA**：每页唯一，`type="primary"`，右上角或底部居中；移动端底部固定。
- **证据角标**：数据断言右上角 `[1][2][3]` 角标，点击弹出「来源」面板。
- **图表**：`ResponsiveChart` 封装，随 Col 宽度 resize，`aria-label` + 可见摘要。
- **状态色带**：任务卡左侧 3px 竖条 + 文字/图标第二编码。
