# SKU Hunters · AI Product Committee

> **不是让 AI"帮你干活"，而是让 AI"替委员会先开一次会"——**
> **把爆款从"灵光一现"变成"数据可推演的确定选择"。**

名创优品 × AI 先锋未来人才大赛参赛方案：一套多 Agent 协同的商品开发智能决策引擎。

---

## 为什么是这个项目

名创优品"711 战略"：每 7 天上 100 款新品，从约 1 万个设计方案中选出——**每周一次 1% 通过率的押注**。

但 2025 上半年财报显示：收入 +21%，净利润 -22.6%。**"推得多"没有转化成"卖得好"**。

我们调研后发现，瓶颈不在执行，在**评审会本身**：市场的人懂趋势不懂毛利，财务懂毛利不懂 Z 世代，海外运营懂本地市场但不在会上——**两小时会议里，没有任何一个人掌握完整信息**。决策质量取决于"谁在场"，而不是"证据是什么"。

AI Product Committee 的答案：用七位各掌一方数据的 AI 委员，把这场会先开一遍。

## 七位委员 · 一场圆桌

```
趋势官 ┐
用户官 ┼─→ 创意官 ─┬─→ 商业官 ──┐
IP官  ┘           └─→ 全球化官 ─┴─→ Decision Engine ─→ 学习官 ─┐
       （并行汇聚）    （双轨并行）         ↓                    │
                                    商品经理拍板          反馈优化
                                    （唯一人工决策点） ←─────────┘
```

| 委员 | 对应真实岗位 | 干什么 |
|:---|:---|:---|
| 🔍 趋势官 | 市场研究总监 | 监测趋势信号，判断生命周期 |
| 👥 用户官 | 用户研究负责人 | 挖真实需求与痛点 |
| 🧸 IP官 | IP 合作经理 | 评 IP 热度与窗口期 |
| 🎨 创意官 | 商品策划经理 | 合成 3-5 个可溯源的方案 |
| 💰 商业官 | 财务评审 | 五维机会值评分 |
| 🌍 全球化官 | 海外运营负责人 | 定国家批次与定价 |
| 📈 学习官 | 数据分析负责人 | 上市后复盘，反哺全员 |

每位委员对应名创一个真实岗位——**Agent 数量由组织架构决定，不由技术炫技决定**。

## 四个让它不是"AI 聊天表演"的设计

**1. 信息隔离——真圆桌和假圆桌的分水岭**
趋势官只看得见趋势数据，用户官只看得见需求数据，创意官只看得见三方结论、看不见任何原始数据。信息差是真实的，汇聚才有增量。隔离靠依赖注入白名单物理实现，不靠 prompt 自觉。

**2. 冲突不调和**
淘宝搜索热、B站创作冷——系统**禁止**把这种信号背离平均掉，因为背离本身揭示趋势所处阶段。所有分歧原样写进建议书，交给商品经理判断。

**3. 每条结论都可对账**
五维机会值评分 = 分项 × 权重的加权算术，每个分项挂 EvidenceRef（来源链接+标题+摘要），Schema 层强制校验——**算错 0.5 分都会被拒绝入库**。

**4. 人机边界清晰**
AI 负责把会开好，人负责拍板。AI 没有"说服权"——系统被禁止生成"您确定要否决吗"这类话术。人否决 AI 高分方案必须留理由，这些理由正是学习官最宝贵的训练信号。

## 技术栈

**LangGraph**（五幕状态图编排：并行汇聚 / checkpoint 挂起续跑 / Human-in-the-loop interrupt）· **FastAPI** · **Pydantic**（契约强制）· **飞书**（企业豆包推理 / aily 工作流 / 多维表格台账 / 妙搭看板 / 妙记留痕）

为什么 LangGraph 而不是 CrewAI/AutoGen：我们的流程不是流水线是图（fan-in 汇聚 + fan-out 并行 + 反馈回路），且评审必须能暂停等人——详见 [架构文档](docs/architecture/overview.md)。

## 快速开始

```bash
git clone https://github.com/steelebluesummer-droid/SKU-Hunters.git
cd SKU-Hunters/backend

python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env   # 填入免费 LLM Key（智谱 GLM-4-Flash 注册即得）

python scripts/demo_review.py       # 五幕评审全流程（mock 委员 + 可交互双门）
python scripts/demo_real_data.py    # 真实数据管道：淘宝+B站双源验证
python scripts/test_llm.py          # LLM 连通性测试（趋势官角色试跑）
python scripts/validate_schemas.py  # 契约校验器行为验证
```
